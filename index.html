Bienvenido

Esta aplicación permite registrar, consultar y controlar los productos de una empresa de una manera sencilla y organizada.

Descripción del proyecto

El proyecto consiste en desarrollar un sistema web de inventario que permita llevar un mejor control de los productos de una empresa. El sistema permite registrar productos, consultar su información, actualizar las existencias y controlar de manera organizada el inventario disponible.

Funciones del sistema

  • Registrar productos
  • Consultar productos
  • Actualizar existencias
  • Eliminar productos
  • Controlar el inventario disponible

Proceso de uso

  1. Ingresar al sistema
  2. Registrar el producto
  3. Consultar la información
  4. Actualizar existencias
